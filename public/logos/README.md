# Logos de plataformas

Archivos PNG con transparencia, recortados al **isologo** (solo el símbolo,
sin la palabra) y cuadrados a 512 px para que todos ocupen el mismo espacio.

Presentes: meta · facebook · instagram · tiktok · google · indeed · whatsapp

`youtube` y `web` no tienen archivo: la app muestra su monograma con el color
de la marca. Para añadirlos, deja aquí `youtube.png` con el mismo tratamiento.

Origen: archivos aportados por el distribuidor. Respeta las guías de uso de
cada marca (espacio libre alrededor, sin recolorear ni deformar).
