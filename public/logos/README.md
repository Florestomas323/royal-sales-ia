# Logos oficiales de plataformas

Coloca aquí el archivo SVG oficial de cada plataforma, descargado del kit de
prensa/marca de cada empresa, con estos nombres exactos:

- meta.svg · facebook.svg · instagram.svg · tiktok.svg
- google.svg · youtube.svg · indeed.svg · whatsapp.svg

Si un archivo falta, la app muestra el monograma con el color de la marca.
Respeta las guías de uso de cada marca (espacio libre, sin recolorear).
